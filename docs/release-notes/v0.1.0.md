## stagegate-agents v0.1.0

**A staged, human-gated delivery pipeline for Claude Code, whose rules are enforced by code.**
Nineteen agents take a feature from idea to merged pull request behind three human approval
gates, while guard hooks, the OS sandbox and CI enforce the rules that matter. Extracted from
[StarPulse](https://starpulse.dev), a production platform on AWS EKS
([case study](https://github.com/BuchbinderNatalia/stagegate-agents/blob/v0.1.0/docs/CASE_STUDY.md)).

### Highlights
- **`/feature-factory`**: researcher → story → ⛔ → brief → ⛔ → test plan → builders → tests →
  validation loop → ⛔ → PR → reviewer → merge gate.
- **Guards that parse the real command:** no commits of secrets or `:latest` images, no commits or
  pushes to `main`, no merging while CI is red, no load tests against remote hosts, even through
  `bash -c`, `eval` or wrappers. 130+ regression tests.
- **Sandbox on by default:** agents can't read `~/.aws`, `~/.ssh`, `~/.kube` or your GitHub login.
- **Optional infra pack** for Terraform, Kubernetes, CI/CD, ArgoCD and monitoring, with a deploy
  workflow using OIDC, SHA-pinned actions and an image-scan gate.
- **Tested end to end offline:** 260+ tests, including a builder cycle and the PR → review → merge
  gate loop through the real installed hooks, plus a success-rate eval with hidden tests.

### Install
```bash
curl -fsSL https://raw.githubusercontent.com/BuchbinderNatalia/stagegate-agents/v0.1.0/scripts/install.sh \
  | STAGEGATE_SHA256=<sha256 from the .sha256 asset below> bash -s -- /path/to/repo
```
Verify where the tarball was built: `gh attestation verify stagegate-agents-v0.1.0.tar.gz --repo BuchbinderNatalia/stagegate-agents`.

Requirements: git, Python 3.11+, Claude Code, GitHub CLI.

### Known limits
Hooks can't see merges done in the GitHub web UI or commands assembled at runtime; the reviewer's
read-only Bash access is an instruction, not enforced per agent. See
[GOVERNANCE](https://github.com/BuchbinderNatalia/stagegate-agents/blob/v0.1.0/docs/GOVERNANCE.md#known-gaps).
